 🚌 GoPass - Cloud-Based Bus Pass System

GoPass is a modern bus pass booking website designed to provide
users with a simple, secure and convenient online booking experience.

✨ Features

- Online bus pass booking
- Automatic fare calculation
- Daily, weekly and monthly passes
- Route selection
- Digital bus pass generation
- Unique Pass ID
- Print digital pass
- Responsive UI/UX design
- Local browser storage
- Mobile-friendly interface

🛠 Technologies

- HTML5
- CSS3
- JavaScript
- LocalStorage
- Responsive Web Design

🚀 How to Run

Open `index.html` in any modern web browser.

 🎯 Project Objective

The project demonstrates how a cloud-based bus pass system can
provide a scalable, reliable and user-friendly booking experience.
